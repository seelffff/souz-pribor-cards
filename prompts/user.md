Подготовь черновик карточки товара. Поля ответа:

1. seo_title — до 70 символов: тип прибора, модель, производитель и главный параметр; ключевая фраза в начале.
2. seo_description — около 1000 символов (допустимо 800–1200), 2–4 абзаца через пустую строку: назначение → ключевые параметры → подключение и конструкция → где применяется.
3. search_queries — 3–5 разных запросов в том виде, как их пишут покупатели (строчными буквами), с параметрами только из входа.
4. commercial_block — для менеджера: audience — кому подходит прибор; tasks — 2–4 задачи, которые он решает; typical_applications_note — где обычно применяют приборы этого класса (формулируй как типовое применение класса, а не как свойство этой модели).
5. facts_from_description — характеристики из текста description, которых нет в specs: field, value и source_quote — дословный фрагмент description, откуда взято значение.
6. clarifications — что стоит уточнить у производителя или поставщика для полноценной карточки, включая расхождения между specs и description.
