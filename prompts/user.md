Подготовь черновик карточки товара. Поля ответа:

1. seo_title — до 70 символов: тип прибора, модель, производитель и главный параметр; ключевая фраза в начале.
2. seo_description — около 1000 символов (допустимо 800–1200), 2–4 абзаца через пустую строку: назначение → ключевые параметры → подключение и конструкция → где применяется. Полная таблица характеристик выводится в карточке отдельно, поэтому в тексте назови 4–6 главных параметров, а не все; каждый параметр — один раз.
3. search_queries — 3–5 разных запросов в том виде, как их пишут покупатели (строчными буквами), с параметрами только из входа.
4. commercial_block — для менеджера: audience — кому подходит прибор; tasks — 2–4 задачи, которые он решает; typical_applications_note — где обычно применяют приборы этого класса (формулируй как типовое применение класса, а не как свойство этой модели).
5. facts_from_description — характеристики из текста description, которых нет в specs: field, value и source_quote — дословный фрагмент description, откуда взято значение.
6. clarifications — 1–4 вопроса к производителю или поставщику, которые помогут дополнить карточку: неясное базовое исполнение, расхождения в данных, неоднозначные формулировки. Спрашивай, какое значение у параметра, не предлагая вариантов. Пустые поля, оборванное описание, код заказа без расшифровки и расхождения степени защиты, резьбы и стандартов система сообщает сама — их не повторяй.
